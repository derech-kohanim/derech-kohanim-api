# certs

תיקייה לתעודות שורש נוספות.

ברשתות שבודקות תעבורה מוצפנת (פרוקסי ארגוני, סינון תוכן) המיירט מציג שרשרת תעודות משלו,
ש-Node ו-npm אינם מכירים. התוצאה נראית כמו תקלה אצל הספק החיצוני, ואינה קשורה אליו כלל.

הפתרון: להעתיק לכאן את תעודת השורש של המיירט בסיומת `.crt`. תמונת הדוקר מתקינה כל קובץ
`.crt` שנמצא כאן לתוך מאגר התעודות של הקונטיינר לפני `npm install`.

```bash
cp /path/to/root-ca.crt certs/
docker compose --profile full build api
```

להרצה מקומית ללא דוקר, יש להצביע על התעודה עם משתנה הסביבה של Node:

```bash
export NODE_EXTRA_CA_CERTS=/path/to/root-ca.crt
```

קובצי `.crt` אינם נכנסים לניהול גרסאות, כי תעודת שורש של ארגון היא עניין של אותו ארגון.
